# Routine – so kommt die App aufs Handy

## 1. Auf GitHub hochladen
1. Auf github.com einloggen → oben rechts **+** → **New repository**.
2. Name z. B. `routine`, auf **Public** lassen → **Create repository**.
3. Auf der neuen Seite: **uploading an existing file** anklicken.
4. Diese Dateien und den Ordner reinziehen:
   - `index.html`
   - `app.js`
   - `styles.css`
   - `manifest.webmanifest`
   - `sw.js`
   - den Ordner `icons`
5. Unten **Commit changes** klicken.

## 2. Als Webseite freischalten
1. Im Repository: **Settings** → links **Pages**.
2. Bei *Branch* **main** und **/(root)** wählen → **Save**.
3. Nach 1–2 Minuten steht oben die Adresse, z. B. `https://DEIN-NAME.github.io/routine/`.

## 3. Aufs Handy
- **iPhone (Safari):** Adresse öffnen → Teilen-Knopf → **Zum Home-Bildschirm**.
- **Android (Chrome):** Adresse öffnen → Menü ⋮ → **App installieren** / **Zum Startbildschirm hinzufügen**.

## Wichtig
- Deine Daten bleiben nur auf dem Handy. Unter *Einstellungen → Sicherung speichern* kannst du ab und zu ein Backup machen.
- Updates: geänderte Dateien einfach wieder hochladen (gleiche Namen, GitHub ersetzt sie). Die App holt sich die neue Version beim nächsten Öffnen mit Internet.
